# Anime opening character

Both public invitations share the full-body anime host on the opening cover. The original family invitations do not load this feature.

The generated artwork is `assets/generated/opening-anime-bride.webp` (1024 × 1536, alpha transparency). It was created with the built-in image generation tool and encoded as lossless WebP, preserving its pixels and transparency while reducing the source PNG from 1,864,158 bytes to 798,750 bytes. The eye whites in the artwork intentionally have no irises: the inline SVG draws movable irises, pupils and highlights over them. The SVG clips and layers the head and body for subtle cursor tracking.

`opening-character.js` is a classic script loaded before `public.js`. It listens only while the opening gate is present, uses passive pointer handlers for mouse and touch, and schedules animation frames only while moving toward a new pose. Manual animation pause, reduced motion, and tab visibility return the host to a neutral pose; opening the invitation removes its listeners and observer.

Edit the shared markup in `src/public-invitation.html`, visual rules in `opening-character.css`, and interaction in `opening-character.js`. Regenerate both public pages with `node scripts/build-public.mjs`. Run `node --test tests/*.test.mjs` for lifecycle, original invitation and music regression checks.

## Generation prompt

Use case: stylized-concept. Asset type: transparent full-body anime character for an interactive wedding invitation opening screen. Primary request: one original adult South Indian anime bride hostess, welcoming and graceful, with complete body and feet visible, front-facing symmetrical pose. Emerald green silk sari with an ornate gold border, burgundy blouse, gold necklace and earrings, dark brown hair in a tidy bun decorated with jasmine, small red bindi, warm brown skin, soft gentle smile, open hands held naturally at waist level. Premium hand-painted anime aesthetic, clean delicate linework, soft cel shading, expressive large almond-shaped eyes. Technical eye constraint: both eyes show only pale warm-white sclera inside black lashes, NO pupils, NO irises, NO eye highlights; pupils will be drawn interactively by the webpage. Face straight forward, level centered head, chin and neck unobstructed, hair and bun entirely above the shoulders, no hanging long braid. Character has charming approximately four-heads-tall proportions with a large readable face. Vertical portrait composition, character centered, enough clear padding around all sides, full silhouette isolated on genuinely transparent alpha background. Even gentle studio lighting, rich emerald/gold details readable at small web sizes, complete hands with anatomically correct fingers. No background, floor, shadow, text, watermark, extra characters, or props.
